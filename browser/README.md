# ⬛ BLACK — чёрный браузер с ИИ-помощником

Лёгкий браузер на чистом JS: **~40 КБ кода, ноль зависимостей, ноль картинок, ноль шрифтов**.
По умолчанию — **ноль внешних запросов**, кроме самой страницы, которую открывает пользователь.
Поэтому почти ничего не «ест»: ни трафика, ни памяти, ни батареи.

## ▶️ Запуск

```bash
node browser/server.mjs     # http://localhost:8090
# или
npm run browser
```

## ✨ Что внутри

- **Вкладки** — добавление, закрытие, переключение; у каждой своя история (← →)
- **Адресная строка** — умная: адрес, домен или просто запрос → поиск
- **5 поисковиков** — Яндекс, DuckDuckGo, Bing, Google, Википедия (настройка)
- **Внутренние страницы** — `browser://start` (стартовая с часами и быстрым доступом),
  `browser://history`, `browser://bookmarks`, `browser://settings`, `browser://help`
- **Закладки и история** — хранятся локально (`localStorage`), история ограничена 300 записями
- **Подсказки** в адресной строке из истории и закладок
- **Горячие клавиши** — Ctrl+T/W/L/K/R, Alt+←/→, `/`
- **Глубокая ссылка** — `?u=https://example.com` открывает страницу сразу
- **Чёрная тема** — чистый чёрный, системные шрифты, анимации только на transform/opacity

## ✦ ИИ-помощник «НОЧЬ»

Полностью **локальный**: правила + мини-база знаний + безопасный калькулятор.
Не качает модели, не ходит в сеть, работает офлайн.

Умеет: считать (`посчитай 15% от 240`), открывать сайты (`открой википедию`),
искать (`найди запрос`), объяснять (`что такое iframe`), переводить (`переведи кот`),
пересказывать страницы (`резюме страницы`), запоминать (`запомни: …`),
шутить, бросать кубик, называть дату и время.

Хочешь полноценный нейросетевой чат — вставь API-ключ OpenAI-совместимого сервиса
на странице `browser://settings`. Без ключа помощник трафика не создаёт вообще.

## ⚠️ Про сайты, которые не открываются

Многие сайты (Google, GitHub, соцсети) запрещают встраивание в чужие страницы
(заголовок `X-Frame-Options`) — это защита от фишинга, и обойти её из чистого
фронтенда нельзя. Для таких страниц BLACK показывает кнопку **«↗ Открыть внешне»**.
Сайты без этой защиты (Википедия, MDN, Hacker News, OpenStreetMap и др.)
открываются прямо внутри BLACK.

## 🧱 Файлы

```
browser/index.html   разметка хрома, вкладок и ИИ-панели
browser/style.css    чёрная тема (~6 КБ)
browser/app.js       движок: вкладки, навигация, история, закладки, страницы
browser/ai.js        помощник НОЧЬ: калькулятор, база знаний, резюме, память
browser/server.mjs   статический сервер без зависимостей
```
