# 🧦 GUILTY AS SOCK! — Scripter Edition

**Крутейший 3D-суд носков. Полноценная фанатская игра по мотивам *Guilty as Sock!* (Demon Max) — с нашими добавками. 100% оригинальный код, графика, звуки и текст: ассеты оригинала не используются.**

> ✨ **Версия 2.2:** исправлен «чёрный экран» в EXE (локальное окно игры теперь грузится без TLS, ошибка загрузки показывается понятным текстом, окно открывается даже при проблемах рендерера) • **графика**: вязаные носки (sheen-ткань), бархатный ковёр, портреты основателей суда в золотых рамах, контактные тени под мебелью, тёплая лужа света от люстры, мягкое свечение JUSTICE. Также в 2.1: **голосовой чат** WebRTC, зал онлайн по коду, FPS-захват мыши, процедурные текстуры (паркет, дамаск, мрамор, ковёр-весы ⚖).

## 🚀 Быстрый старт

### Вариант А — EXE для Windows (ничего устанавливать не надо)
1. Откройте **[Releases](https://github.com/squezech-cmd/scripter/releases)** → скачайте `GUILTY-AS-SOCK-Scripter-Edition-Windows-x64.zip` из последнего релиза.
2. Распакуйте куда угодно → запустите **`GUILTY AS SOCK - Scripter Edition.exe`**.
3. Windows спросит про сеть → разрешите **частные сети** (нужно для игры с друзьями).

### Вариант Б — из исходников (Windows / macOS / Linux)
Нужен [Node.js 18+](https://nodejs.org). Дальше:
```bash
git clone https://github.com/squezech-cmd/scripter.git
cd scripter
npm install
npm start          # → https://localhost:8080
```
На Windows можно просто дважды щёлкнуть **`Играть.bat`**.

> ⚠️ **Сертификат самоподписанный** — браузер покажет страшное предупреждение «Подключение не защищено». Это нормально: игра локальная. Жмите **«Дополнительно» → «Перейти на сайт»**. Игра работает по HTTPS, потому что **микрофон браузер даёт только на HTTPS** (или localhost).
> Если совсем мешает — `GAS_HTTP=1 npm start`, но войс-чата на Wi-Fi не будет.

### Вариант В — просто открыть `index.html`
Работает, но **только одиночный режим** и голос недоступен. Для полной игры — варианты А и Б.

## 🌐 Как играть с друзьями (2–8 человек)

1. **Хост** (на чьём ПК запущена игра): главное меню → **🌐 ИГРАТЬ С ДРУЗЬЯМИ** → **🏛️ СОЗДАТЬ ЗАЛ**.
2. Игра сразу попросит **микрофон** — разрешите (иначе друзья будут вас слышать плохо/не слышать). Появится **код зала** (например, `X7QKM`) и **ссылка** `https://192.168.1.50:8787/juror.html?room=X7QKM` — кнопка «📋 Копировать».
3. **Друзья** открывают ссылку на телефоне/ноутбуке (та же Wi-Fi) → предупреждение о сертификате → «Перейти на сайт» → вводят код (или сразу по ссылке) → тоже разрешают микрофон → **«ВОЙТИ И ГОВОРИТЬ»**.
4. **Готово. Все слышат всех.** Прямо в 3D-зале суда, как по Discord, без сторонних программ:
   - 🎙️ **Голосовой чат** (WebRTC, P2P-меш между всеми участниками — сервер только сводит людей);
   - 🗳️ голоса «ВИНОВЕН / НЕВИНОВЕН» — **учитываются в вердикте**;
   - 📄 бумажные комки летят в 3D-зал из трибуны (отвлекают выступающего, −убедительность);
   - 💬 запасной текстовый чат — на случай, если микрофон не завёлся;
   - 📺 у друзей живой экран: фаза суда, шкалы обвинения/защиты, хаос-метр, счёт голосов.
5. Хост играет как обычно. Друзья могут оставаться в зале несколько дел подряд (Best of 5).

### 📡 В одной Wi-Fi
Работает сразу: телефон и ПК в одной сети, при первом запуске разрешите **частную сеть** в брандмауэре Windows. IP хоста покажут и консоль (`npm start`), и окно «Играть с друзьями».

### 🌍 Через интернет
Поставьте всем **[Tailscale](https://tailscale.com)** (бесплатный VPN в один клик): хост создаёт зал, друзья открывают ссылку по Tailscale-IP хоста. Никаких пробросов портов. Для голоса важно, что Tailscale — приватная сеть; WebRTC сам найдёт путь между участниками.

### ❓ Частые вопросы
- **«Ваше подключение не защищено» / красный экран браузера?** Это самоподписанный сертификат — «Дополнительно» → «Перейти на сайт». Иначе микрофон не дадим ни нам, ни браузеру.
- **Микрофон не работает?** Проверьте: (1) вы открыли игру по **https://** или `localhost` (не `http://192.168...`); (2) разрешение на микрофон в адресной строке; (3) в EXE — что Windows не заблокировала микрофон приложению (Параметры → Конфиденциальность → Микрофон).
- **Друзья вас не слышат, но вы всех слышите.** Ваше устройство не отдало микрофон — перезайдите в зал и разрешите; или включите 🎙️ в правом нижнем углу HUD (клавиша `M`).
- **Совсем нет микрофона / не хотите говорить.** Не страшно: слышать зал будете всегда. Голосуйте, кидайте комки, пишите в текстовый чат.
- **Порт занят?** `GAS_PORT=8081 npm start` (в игре ссылка обновится сама), EXE возьмёт свободный порт автоматически.
- **Хост закрыл игру** → зал закрывается у всех автоматически.

## ⚖️ Что это за игра

Это зал суда, где все — носки. Идёт дело, у прокурора и адвоката карты-доказательства, присяжные голосуют, свидетель путается в показаниях, журналист продаёт сенсации, пристав пытается удержать порядок… а кто-то кидает бумажные комки в говорящего.

Один суд — примерно **1.5–2 минуты**. Матч — **best of 5** (до 3 побед). Каждый третий суд — **«Дневное дело»**, генерируемое по дате.

### 7 ролей
| Роль | Что делает |
|---|---|
| ⚖️ Судья | Ведёт заседание, бьёт молотком (`Q`), гасит хаос, выносит вердикт |
| 👨‍⚖️ Прокурор | Обвиняет, выкладывает доказательства, давит на присяжных |
| 🛡️ Адвокат | Защищает обвиняемого, ломает обвинение контраргументами |
| 👁️ Свидетель | Показания, которые могут перевернуть дело |
| 🗳️ Присяжный | Слушает и голосует: ВИНОВЕН / НЕВИНОВЕН |
| 📰 Журналист | Публикует 3 заголовка-сенсации за суд — тоже доказательства |
| 🚪 Пристав | Восстанавливает порядок в зале |

### 🃏 Доказательства и стили
Рука — 5 карт из колоды (30 карт; 6 колод: Классика, Абсурд, Детектив, Sci-Fi, Королевская, Эмо).

- 📐 **Логика** ×1.25 — строгие факты
- ❤️ **Эмоции** ×1.15 — слёзы и драма
- 🎪 **Хаос** ×1.05 — но +3 к хаосу в зале
- 💸 **Подкуп** ×1.0 — шоколадки присяжным

Убедительность = карта × стиль + бонус колоды + харизма носка.

## 🕹️ Управление

| Клавиша | Действие |
|---|---|
| `WASD` / стрелки | Ходить |
| Клик по залу | Захват мыши (FPS-обзор); `Esc` — отпустить |
| Мышь | Обзор |
| `Shift` | Бежать |
| `Пробел` | Прыжок |
| `ЛКМ` | Бросить бумажный комок |
| `E` | Поговорить с носком рядом |
| `R` | ВОЗРАЖЕНИЕ! |
| `Q` | Молоток (роль судьи) |
| `M` | Вкл/выкл микрофон (когда зал онлайн) |
| `Esc` | Пауза |

Доказательства: клик по карте → клик по стилю → **⚖️ ПРЕДЪЯВИТЬ**.
На телефоне — сенсорные кнопки на экране.

## 🧱 Сборка EXE самому

```bash
npm ci                 # зависимости (нужен интернет один раз — скачается Electron)
npm test               # проверка (jsdom-прогон игры + WebSocket/WebRTC-сигналинг + HTTPS)
npm run dist:win       # → release/GUILTY AS SOCK - Scripter Edition-win32-x64/
```
В папке появится `GUILTY AS SOCK - Scripter Edition.exe` — можно в zip и отдавать друзьям.
CI (`.github/workflows/build-exe.yml`) собирает **Windows x64 EXE на каждый тег `v*`** и прикладывает к GitHub Release автоматически. Локально на Linux/macOS тоже работает: `node scripts/build-exe.mjs --platform=linux --arch=x64`.

## 📁 Структура
```
index.html            разметка экранов и HUD

js/data.js            роли, дела, карты, колоды, темы, реплики, достижения

js/ai.js              ИИ: карты, стили, убедительность, голосование
js/audio.js           WebAudio-синтез звуков
js/net.js             сетевой клиент зала (хост и присяжный)
js/voice.js           🎙️ голосовой чат (WebRTC mesh + perfect negotiation)
js/main.js            движок: FPS-камера, ввод, режиссёр суда, физика комков, FX, UI
server/room-server.mjs  общий сервер: HTTPS + статика + WebSocket-зал + сигналинг
electron/main.mjs     EXE-обёртка (свой HTTPS + окно игры + микрофон)
scripts/serve.mjs     `npm start` — локальный сервер
scripts/build-exe.mjs сборка EXE (electron-packager)
test/                 headless-тесты (game + relay)
Играть.bat            двойной клик в Windows → игра в браузере
```
