# BLACK

Небольшая Windows-программа с тёмным интерфейсом и локальным помощником. Использует установленный Microsoft Edge WebView2 Runtime, а не собственный движок. Готовый файл: [скачать BLACK.exe](../../raw/refs/heads/arena/6c3941d0-scripter/BLACK.exe).

## Ограничения

- Нужна Windows x64 и установленный WebView2 Runtime (обычно уже установлен в Windows 10/11).
- Это оболочка над WebView2, а не полноценный самостоятельный браузер. Сайты открываются во встроенных iframe; многие запрещают такое встраивание. В этом случае используйте «Открыть внешне» — ссылка откроется в браузере по умолчанию.
- Помощник «НОЧЬ» без API-ключа работает по правилам, это не нейросеть. Дополнительный внешний API требует интернета, ключа, совместимого сервиса и поддержки CORS; ключ сохраняется в локальном хранилище без шифрования.
- Сборка не подписана цифровой подписью. Она собрана для Windows, но автоматическая проверка запуска на Windows не выполнялась.
- Данные интерфейса хранятся в профиле WebView2; порт `127.0.0.1:43671` используется только локально. Одновременно запускается одна копия приложения.

## Сборка EXE из исходников

Установите Go 1.21 или новее и выполните:

```sh
cd browser
go mod tidy
GOOS=windows GOARCH=amd64 CGO_ENABLED=0 go build -ldflags="-s -w -H windowsgui" -o BLACK.exe .
```

Для просмотра веб-версии можно запустить `node browser/server.mjs` и перейти на `http://localhost:8090`.
