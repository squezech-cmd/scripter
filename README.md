# Burger Shift: Diner Edition

Небольшая самостоятельная 3D-игра про работу в бургерной, вдохновлённая Burger Shift: Team Rush. Это **не оригинальная игра и не её точная копия**: здесь одна кухня и одиночная игра, без сетевого кооператива. Интернет для игры не нужен.

## Запуск

На Windows 10/11 x64 скачайте `BurgerShift.exe` и запустите двойным щелчком. Отдельно устанавливать Python или игровой движок не требуется. При запуске игра временно распаковывает свои файлы, поэтому потребуется свободное место во временной папке; первый запуск может занять немного времени. Приложение не подписано цифровой подписью.

Сборка проверена под Wine: запущен EXE и пройдён заказ с клавиатуры и мыши. На настоящей Windows, с аппаратным OpenGL и звуком она пока не проверена.

Игра сохраняет карьеру в `%APPDATA%\BurgerShiftDiner\profile.json`. День и выручка записываются **после окончания смены**; если выйти или начать смену заново раньше, её текущий результат не сохранится. После смены можно потратить заработанное на улучшения.

## Управление

- **W, A, S, D** — передвижение; **Shift** — бег; **мышь** — обзор.
- **E** или **левая кнопка мыши** — взять, положить или выдать предмет, на который наведён прицел. Подойдите к нужной станции до появления подсказки.
- **F** — перевернуть котлету на гриле; **R** — завернуть бургер на столе сборки.
- **Q** — выбросить предмет из рук. У корзины можно также очистить стол сборки.
- **Esc** — пауза / продолжить.

## Первая смена

1. Возьмите сырую котлету в холодильнике, положите её на гриль и обжарьте **обе стороны** минимум до 85%. Переверните клавишей F, затем заберите клавишей E. Если передержать, котлета сгорит.
2. У стола сборки положите котлету; булочка добавится автоматически. Возьмите ингредиенты со стойки и по одному добавьте их на стол точно по составу чека. Нажмите R.
3. Отнесите бургер к выдаче. Картошку из фритюрницы и напиток, если они указаны в заказе, выдавайте отдельно. Готовый предмет автоматически добавляется к первому подходящему заказу.
4. Следите за временем и терпением гостей. В конце четырёхминутной смены откроются результаты и улучшения.

В игре есть пять вариантов бургера, фри, напитки, чаевые и три типа улучшений. При отсутствии рабочего OpenGL-устройства используется программный рендерер, который может работать медленнее.

## Запуск из исходников и тесты

Нужен Python 3.11 и зависимости из `requirements-dev.txt`:

```sh
python -m pip install -r requirements-dev.txt
python main.py
python -m pytest -q
```

`python main.py --offscreen --screenshot menu.png` создаёт тестовый снимок меню без окна и звука. Для пересборки Windows-приложения на поддерживаемой платформе:

```sh
python setup.py build_apps
python tools/pack_windows.py
```

Вторая команда упаковывает `build/win_amd64` в один `BurgerShift.exe` и при необходимости скачивает проверенные по SHA-256 инструменты 7-Zip. Можно передать локальные инструменты через `--sevenzip` и `--sfx`.

Игра использует Panda3D, шрифты DejaVu и SFX-модуль из LZMA SDK. Уведомления и лицензии сторонних компонентов находятся в `assets/licenses/` и `assets/fonts/LICENSE-DejaVu.txt`. Все модели, текстуры, звуки и оформление для этой версии созданы отдельно от оригинальной игры.
