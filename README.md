# Burger Shift: Diner Edition

Самостоятельная 3D-игра про работу в бургерной, вдохновлённая **Burger Shift: Team Rush**. Можно играть одному или командой до восьми человек: готовить заказы на общей кухне, общаться в текстовом чате и улучшать ресторан.

Это не оригинальная игра и не её точная копия: кухня, правила и оформление отличаются от Team Rush. Оригинальные игровые ассеты не используются.

## Скачать и запустить

1. На Windows 10/11 **x64** скачайте [BurgerShift.exe](https://github.com/squezech-cmd/scripter/raw/refs/heads/arena/63d81c35-scripter/BurgerShift.exe) и запустите файл двойным щелчком.
2. Отдельно устанавливать Python или игровой движок не требуется. Игра временно распаковывает файлы, поэтому ей нужно свободное место в системной временной папке. Первый запуск может занять некоторое время. Файл не подписан цифровой подписью.
3. Для одиночной смены интернет не нужен.

EXE проверялся под Wine с программным рендерером; на настоящей Windows, с аппаратным OpenGL и звуком сборка пока не проверена. Если OpenGL недоступен, используется более медленный программный рендерер.

## Как играть вместе

У всех участников должна быть **одинаковая свежая версия** `BurgerShift.exe`. Старые версии не поддерживают интернет-ссылку. Максимум — восемь игроков, включая хоста.

### Через интернет, из разных сетей

1. Хост выбирает **«Играть с друзьями»**, вводит имя и нажимает **«Создать интернет»**. Подождите до минуты, пока создаётся временная комната. Открывать порт на роутере обычно не требуется.
2. В комнате хост нажимает **«Копировать»** и отправляет ссылку друзьям целиком. Код уже включён в ссылку; никому постороннему её не передавайте.
3. Гость выбирает **«Играть с друзьями»**, вводит имя, нажимает **«Вставить ссылку»**, затем **«Войти»**. Хост нажимает **«Начать смену»**. Можно присоединиться и к уже идущей смене, если есть место.
4. У каждого свои руки и предметы; заказы, кухня и уборка общие. В комнате есть текстовый чат: во время смены нажмите **T**, наберите сообщение и нажмите **Enter**. Голосового чата нет.

Интернет-режим использует временный сторонний **Cloudflare Quick Tunnel**, без регистрации и без гарантии доступности. Ссылка меняется после каждого создания комнаты и перестаёт работать, когда хост выходит. Соединение гостя с Cloudflare шифруется, но **не является сквозным**: сервис может видеть трафик. Ссылка и код дают доступ в комнату, поэтому делитесь ими только с доверенными людьми. Это не официальный сервер Burger Shift.

Если не удаётся создать комнату или войти, проверьте интернет и доступ к Cloudflare у обоих игроков, разрешите игре и `cloudflared.exe` исходящие соединения в брандмауэре и попробуйте создать новую ссылку. Хосту нужен исходящий доступ к Cloudflare Tunnel, в том числе через порт 7844; гостю — HTTPS/WSS через порт 443. Некоторые провайдеры, прокси и корпоративные сети могут блокировать сервис. Если он недоступен, используйте LAN или общую VPN-сеть.

### Локальная сеть / VPN

Хост выбирает **«Создать LAN»** и передаёт друзьям показанные в комнате IPv4-адрес, TCP-порт и шестизначный код. Если адрес неверный, найдите IPv4 нужного адаптера командой Windows `ipconfig`. Гость вводит адрес, порт и код и нажимает **«Войти»**. Порт по умолчанию — **38447**; брандмауэр хоста может спросить разрешение на входящее TCP-соединение. LAN-соединение и чат **не шифруются**, поэтому используйте доверенную сеть. Прямое подключение через интернет может дополнительно потребовать VPN или проброса порта и зависит от провайдера.

Комната закрывается при выходе хоста. В сетевой игре меню паузы действует только локально: таймер смены и действия других игроков продолжаются. Результаты и улучшения сохраняются **у хоста**, а личное одиночное сохранение гостей не заменяется.

## Управление

- **W, A, S, D** — движение; **Shift** — бег; **мышь** — обзор.
- **E** или **левая кнопка мыши** — взять, положить или выдать предмет, на который наведён прицел. Подойдите к станции до появления подсказки.
- **F** — перевернуть котлету на выбранной части гриля; **R** — завернуть бургер на столе сборки.
- **Q** — убрать предмет из рук. У корзины также можно очистить стол сборки.
- **T** — открыть текстовый чат во время совместной смены; **Enter** — отправить сообщение, **Esc** — закрыть ввод.
- **Esc** — пауза / продолжить; в сетевой игре смена при этом не останавливается.

## Первая смена

1. Возьмите сырую котлету в холодильнике и положите на одну из **трёх независимых секций гриля**. Обжарьте обе стороны минимум до 85%, переверните клавишей F и заберите клавишей E. Если передержать, котлета сгорит.
2. У стола сборки положите котлету: булочка добавится автоматически. Возьмите начинку со стойки, по одному добавьте ингредиенты точно по чеку и нажмите R.
3. Отнесите бургер к выдаче. Картошку фри, газировку и кофе, если они указаны в чеке, выдавайте отдельно. Предмет автоматически добавляется к первому подходящему заказу.
4. Мусор копится в корзине. Когда она заполнится, освободите руки, заберите мешок и отнесите его в контейнер у правой стены. После обслуживания можно убрать столы в зале за дополнительную награду.
5. Следите за временем и терпением гостей. После четырёхминутной смены откроются результаты и улучшения. В игре есть пять рецептов бургеров, чаевые и три типа улучшений.

Прогресс записывается в `%APPDATA%\BurgerShiftDiner\profile.json` **после окончания смены**. Если выйти раньше, результат текущей смены не сохранится. Улучшения покупаются между сменами.

## Исходники и тесты

Нужен Python 3.11 и зависимости из `requirements-dev.txt`:

```sh
python -m pip install -r requirements-dev.txt
python main.py
python -m pytest -q
```

`python main.py --offscreen --screenshot menu.png` создаёт тестовый снимок меню без окна и звука. `--screenshot-game game.png` снимает игровую сцену. Для интернет-комнаты при запуске из исходников отдельно нужен `cloudflared` в `PATH` или путь к нему в переменной `BURGER_CLOUDFLARED`; в Windows EXE коннектор уже включён. Для пересборки Windows-приложения на поддерживаемой платформе:

```sh
python setup.py build_apps
python tools/pack_windows.py
```

Вторая команда упаковывает `build/win_amd64` в один `BurgerShift.exe`, при необходимости скачивает инструменты 7-Zip и включает коннектор Cloudflare; загружаемые компоненты проверяются по SHA-256. Можно передать локальные файлы через `--sevenzip`, `--sfx` и `--cloudflared`.

Используются Panda3D, библиотека websockets, cloudflared, шрифты DejaVu, SFX-модуль LZMA SDK и переработанные CC0-модели персонажей и анимации. Источники и лицензии — в `assets/licenses/` и `assets/fonts/LICENSE-DejaVu.txt`; остальные объекты, текстуры, звуки и оформление сделаны для этой самостоятельной версии.

Ранее находившаяся в репозитории браузерная игра сохранена; её документация — в [README-GuiltyAsSock.md](README-GuiltyAsSock.md).
