# 🧦 GUILTY AS SOCK! — Scripter Edition

**Крутейший 3D-суд носков. Полноценная фанатская игра по мотивам *Guilty as Sock!* (Demon Max) — с нашими добавками. 100% оригинальный код, графика, звуки и текст: ассеты оригинала не используются.**

> ✨ **Главное в версии 2.0:** играйте **с друзьями онлайн** — хост создаёт зал по коду, друзья заходят с телефонов/ПК, голосуют «ВИНОВЕН / НЕВИНОВЕН» (голоса влияют на вердикт), **кидают бумажные комки в 3D-зал** и пишут в чат суда в реальном времени. Плюс готовый **EXE для Windows**.

## 🚀 Быстрый старт

### Вариант А — EXE для Windows (ничего устанавливать не надо)
1. Откройте **[Releases](https://github.com/squezech-cmd/scripter/releases)** → скачайте `GUILTY-AS-SOCK-Scripter-Edition-Windows-x64.zip` из последнего релиза.
2. Распакуйте куда угодно → запустите **`GUILTY AS SOCK - Scripter Edition.exe`**.
3. Windows спросит про сеть → разрешите **частные сети** (нужно для игры с друзьями).

### Вариант Б — из исходников (Windows / macOS / Linux)
Нужен [Node.js 18+](https://nodejs.org). Дальше:
```bash
git clone https://github.com/squezech-cmd/scripter.git
cd scripter
npm install
npm start          # → http://localhost:8080
```
На Windows можно просто дважды щёлкнуть **`Играть.bat`**.

### Вариант В — просто открыть `index.html`
Работает, но **только одиночный режим** (нужен Chrome/Edge/Firefox). Трёхмерному залу нужен доступ к файлам, поэтому онлайн-зал доступен в вариантах А и Б.

## 🌐 Как играть с друзьями (2–8 человек)

1. **Хост** (на чьём ПК запущена игра): главное меню → **🌐 ИГРАТЬ С ДРУЗЬЯМИ** → **🏛️ СОЗДАТЬ ЗАЛ**.
2. Появится **код зала** (например, `X7QKM`) и **ссылка** вида `http://192.168.1.50:8787/juror.html?room=X7QKM` — кнопка «📋 Копировать».
3. **Друзья** открывают ссылку на телефоне/ноутбуке (или вручную вводят код на странице `/juror.html`). Готово — они **онлайн-присяжные**:
   - 🗳️ голосуют «ВИНОВЕН / НЕВИНОВЕН» — голоса **учитываются в вердикте** (можно отключить галочкой в окне «Играть с друзьями»);
   - 📄 кидают **бумажные комки** — они реально летят в 3D-зал из трибуны (комок отвлекает выступающего и снижает его убедительность);
   - 💬 пишут в **чат зала** — виден и в игре, и на телефонах;
   - 📺 на своём экране видят: фазу суда, шкалы обвинения/защиты, хаос-метр и счёт голосов.
4. Хост играет как обычно. Друзья могут оставаться в зале несколько дел подряд (Best of 5).

### 📡 В одной Wi-Fi
Работает сразу: телефон и ПК должны быть в одной сети, при первом запуске разрешите приложению/Node доступ в **частной сети** в брандмауэре Windows. IP хоста покажут и консоль (`npm start`), и окно «Играть с друзьями».

### 🌍 Через интернет
Поставьте всем **[Tailscale](https://tailscale.com)** (бесплатный VPN в один клик): хост создаёт зал, друзья открывают ссылку по Tailscale-IP хоста вместо `192.168.x.x`. Никаких пробросов портов не нужно.

### ❓ Частые вопросы
- **Код не подходит?** Проверьте, что хост не закрывал зал (кнопка «Закрыть зал») и что все в одной сети.
- **Телефон не открывает ссылку?** Выключите мобильный интернет на телефоне (оставьте Wi-Fi), попробуйте `http://<IP>:<порт>/juror.html` вручную.
- **Порт 8080/8787 занят?** Запустите на другом: `PORT=8081 npm start` (ссылка в игре обновится сама), EXE возьмёт свободный порт автоматически.
- **Игра закрылась у хоста** → зал закрывается для всех автоматически.

## ⚖️ Что это за игра

Это зал суда, где все — носки. Идёт дело, у прокурора и адвоката карты-доказательства, присяжные голосуют, свидетель путается в показаниях, журналист продаёт сенсации, пристав пытается удержать порядок… а кто-то кидает бумажные комки в говорящего.

Один суд — примерно **1.5–2 минуты**. Матч — **best of 5** (до 3 побед). Каждый третий суд — **«Дневное дело»**, генерируемое по дате.

### 7 ролей
| Роль | Что делает |
|---|---|
| ⚖️ Судья | Ведёт заседание, бьёт молотком (`Q`), гасит хаос, выносит вердикт |
| 👨‍⚖️ Прокурор | Обвиняет, выкладывает доказательства, давит на присяжных |
| 🛡️ Адвокат | Защищает обвиняемого, ломает обвинение контраргументами |
| 👁️ Свидетель | Показания, которые могут перевернуть дело |
| 🗳️ Присяжный | Слушает и голосует: ВИНОВЕН / НЕВИНОВЕН |
| 📰 Журналист | Публикует 3 заголовка-сенсации за суд — тоже доказательства |
| 🚪 Пристав | Восстанавливает порядок в зале |

### 🃏 Доказательства и стили
Рука — 5 карт из колоды (30 карт; 6 колод: Классика, Абсурд, Детектив, Sci-Fi, Королевская, Эмо).

- 📐 **Логика** ×1.25 — строгие факты
- ❤️ **Эмоции** ×1.15 — слёзы и драма
- 🎪 **Хаос** ×1.05 — но +3 к хаосу в зале
- 💸 **Подкуп** ×1.0 — шоколадки присяжным

Убедительность = карта × стиль + бонус колоды + харизма носка.

## 🕹️ Управление

| Клавиша | Действие |
|---|---|
| `WASD` / стрелки | Ходить |
| Мышь | Обзор (наведите курсор на 3D-сцену) |
| `Shift` | Бежать |
| `Пробел` | Прыжок |
| `ЛКМ` | Бросить бумажный комок |
| `E` | Поговорить с носком рядом |
| `R` | ВОЗРАЖЕНИЕ! |
| `Q` | Молоток (роль судьи) |
| `Esc` | Пауза |

Доказательства: клик по карте → клик по стилю → **⚖️ ПРЕДЪЯВИТЬ**.
Меню паузы/выхода: `Esc`. Всё на телефоне — сенсорные кнопки на экране.

## 🧱 Сборка EXE самому

```bash
npm ci                 # зависимости (нужен интернет один раз — скачается Electron)
npm test               # проверка, что игра цела (jsdom + WebSocket-зал)
npm run dist:win       # → release/GUILTY AS SOCK - Scripter Edition-win32-x64/
```
В папке появится `GUILTY AS SOCK - Scripter Edition.exe` — его можно в zip и раздавать друзьям.
CI (`.github/workflows/build-exe.yml`) собирает **Windows x64 EXE на каждый тег `v*`** и прикладывает к GitHub Release автоматически. Локально на Linux/macOS команда тоже работает (собирается win32-пакет; на macOS/Linux для смены платформы: `node scripts/build-exe.mjs --platform=linux --arch=x64`).

## ✅ Тесты

```bash
npm test
```
Два набора:
1. **Headless-прогон игры** (jsdom + fake timers): загрузка, меню, редактор носка, колоды, лобби, суд целиком, предъявление доказательств, комки, пауза/резюм, вердикт, все 7 ролей, стример-чат, сохранение прогресса.
2. **Тест зала онлайн** (`test/relay.test.mjs`): поднятие WebSocket-сервера, создание зала, вход присяжного, рассылка состояния, голоса, чат, комки, отключение хоста.

## 📁 Структура
```
index.html            разметка экранов и HUD
juror.html            телефон присяжного (голоса/комки/чат) — без зависимостей
css/style.css         тёмное золото-суконное оформление + адаптив
js/data.js            роли, дела, карты, колоды, темы, реплики, достижения
js/sock.js            генератор 3D-носка + анимации
js/courtroom.js       процедурный зал суда и 4 темы
js/ai.js              ИИ: карты, стили, убедительность, голосование
js/audio.js           WebAudio-синтез звуков
js/net.js             клиент зала онлайн (хост)
js/main.js            движок: камера, ввод, режиссёр суда, физика комков, UI
server/room-server.mjs  общий сервер: статика + WebSocket-зал (комнаты по коду)
electron/main.mjs     EXE-обёртка (поднимает сервер и окно игры)
scripts/serve.mjs     `npm start` — локальный сервер
scripts/build-exe.mjs сборка EXE (electron-packager)
test/                 headless-тесты (game + relay)
Играть.bat            двойной клик в Windows → игра в браузере
```
