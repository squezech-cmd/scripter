# 🧦 GUILTY AS SOCK! — Scripter Edition

**3D-суд носков прямо в браузере. Без установки, без лаунчера, без аккаунта.**
Полноценная фанатская 3D-игра по мотивам *Guilty as Sock!* — со своими режимами, механиками и графикой на Three.js.

> Вся графика, звуки и текст — процедурные и оригинальные. Никакие ассеты, модели или тексты из оригинала не используются.

---

## ▶️ Как играть

**Вариант 1 — просто открыть:**
```
index.html
```
(браузер должен поддерживать ES-модули; Chrome/Edge/Firefox/Safari — ок)

**Вариант 2 — локальный сервер (рекомендуется):**
```bash
npm start        # http://localhost:8080
```

Ничего скачивать не нужно: Three.js лежит в `vendor/`, CDN не требуется — игра работает офлайн.

## ⚖️ Что это за игра

Это зал суда, где все — носки. Идёт дело, у прокурора и адвоката карты-доказательства,
присяжные голосуют, свидетель путается в показаниях, журналист продаёт сенсации,
пристав пытается удержать порядок… а кто-то кидает бумажные комки в говорящего.

Один суд — примерно **1.5–2 минуты**. Матч — **best of 5 (до 3 побед)**.

### 7 ролей

| Роль | Что делает |
|---|---|
| ⚖️ Судья | Ведёт заседание, бьёт молотком, гасит хаос, даёт слово, выносит вердикт |
| 👨‍⚖️ Прокурор | Обвиняет, выкладывает доказательства, давит на присяжных |
| 🛡️ Адвокат | Защищает обвиняемого, ломает обвинение контраргументами |
| 👁️ Свидетель | Даёт показания, которые могут перевернуть дело |
| 🗳️ Присяжный | Слушает и голосует: ВИНОВЕН / НЕВИНОВЕН |
| 📰 Журналист | Публикует 3 заголовка-сенсации за суд — это тоже доказательства |
| 🚪 Пристав | Восстанавливает порядок и выгоняет хаотиков |

### 🃏 Доказательства и стили
Рука — 5 карт из 30 (след носка, видео, кот-свидетель, инопланетянин, бабушка, портал…).
Выбираешь карту + стиль аргументации:

- 📐 **Логика** ×1.25 — строгие факты
- ❤️ **Эмоции** ×1.15 — слёзы и драма
- 🎪 **Хаос** ×1.05 — но +3 к хаосу в зале
- 💸 **Подкуп** ×1.0 — шоколадки присяжным

Убедительность = карта × стиль + бонус колоды + харизма носка.

## ✨ Наши добавки (Scripter Addons)

- 🎪 **Хаос-метр** — растёт от комков, возражений и хаос-аргументов; на 100% судья начинает орать.
- 📄 **Физика бумажных комков** — реальные 3D-снаряды: попадание сбивает убедительность говорящего.
- 🔴 **Стример-режим** — живой чат и голосование зрителей, которое реально влияет на вердикт.
- 🧦 **Редактор носка Pro** — цвет, узор (полоски/горошек/клетка/пламя), 8 аксессуаров, 5 костюмов, харизма, имя.
- 🃏 **6 колод доказательств** — Классика, Абсурд, Детектив, Sci-Fi, Королевская, Эмо.
- 🎨 **4 темы зала суда** — Классика, Неон-сити, Средневековье, Конфетный.
- 📅 **Дневное дело** — каждый третий суд особенный, генерируется по дате.
- 🏆 **8 достижений** и сохранение прогресса (`localStorage`).
- 📱 **Мобильное управление** — джойстик, свайп-обзор, кнопки броска/возражения.
- 🔊 **Процедурный звук** — молоток, возражения, комки, фанфары: всё синтезируется WebAudio, ни одного аудиофайла.

## 🕹️ Управление

| Клавиша | Действие |
|---|---|
| `WASD` / стрелки | Ходить |
| Мышь | Обзор (наведение на 3D-сцену) |
| `Shift` | Бежать |
| `Пробел` | Прыжок |
| `ЛКМ` | Бросить бумажный комок |
| `E` | Заговорить с носком рядом |
| `R` | ВОЗРАЖЕНИЕ! |
| `Q` | Молоток (роль судьи) |
| `Esc` | Пауза |

Доказательства: клик по карте → клик по стилю → **⚖️ ПРЕДЪЯВИТЬ**.

## 🧱 Технологии

- **Three.js r160** (локально в `vendor/`, ES-модуль)
- Чистый JS (ES-модули), без сборщика и фреймворков
- Все 3D-модели носков и зала суда — процедурные (латентная геометрия, примитивы, canvas-текстуры)
- Звук — WebAudio-синтез
- Сохранение — `localStorage`

```
index.html          разметка всех экранов и HUD
css/style.css       стили, тёмно-золотая тема, мобильная адаптация
js/data.js          роли, дела, карты, колоды, темы, реплики, достижения
js/sock.js          генератор 3D-носка + анимации (рот, жесты, ходьба)
js/courtroom.js     процедурный зал суда и 4 темы
js/ai.js            ИИ: выбор карты, стиль, убедительность, голосование
js/audio.js         синтез звуков
js/main.js          движок: камера, ввод, режиссёр суда, физика комков, UI
vendor/             three.module.min.js
test/               headless-тесты (jsdom + fake timers)
```
