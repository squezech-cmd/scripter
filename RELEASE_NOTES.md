# 🧦 GUILTY AS SOCK! — Scripter Edition v2.1.1

**Хотфикс: EXE падал при запуске с `ERR_MODULE_NOT_FOUND`. Теперь собирается правильно.**

### Что было сломано
В сборке EXE (scripts/build-exe.mjs) node_modules фильтровался руками белым списком «только ws», а игре с v2.1.0 нужен ещё и **selfsigned** (HTTPS-сервер зала, чтобы браузеры разрешали микрофон). В готовый архив попадал только `ws` — и при запуске игра падала с диалогом «A JavaScript error occurred in the main process».

### Что исправлено
- Убран ручной фильтр node_modules — production-зависимости (ws, selfsigned, pkijs, @peculiar/x509 и их зависимости) отбирает штатный pruner `@electron/packager`.
- Добавлена **проверка сборки**: если в собранный app не попал любой runtime-модуль или файл (`electron/main.mjs`, `server/room-server.mjs`, `index.html`), сборка падает с понятной ошибкой — битый EXE больше не уйдёт в релиз.
- В архив больше не попадёт локальная папка `.cache/` (автосертификаты).
- Игра сама по себе не менялась — только сборка.

### Установка (Windows)
1. Скачайте `GUILTY-AS-SOCK-Scripter-Edition-Windows-x64.zip` из этого релиза.
2. Распакуйте в любую папку, запустите **`GUILTY AS SOCK - Scripter Edition.exe`**.
3. При первом запуске разрешите частную сеть (иначе друзья не подключатся к залу) и микрофон (для войс-чата).

Если у вас был установлен v2.1.0 — просто замените файлы на новые из этого релиза.

Исходники и инструкции: https://github.com/squezech-cmd/scripter
