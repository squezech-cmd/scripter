# 🧦 GUILTY AS SOCK! — Scripter Edition v2.1.0

**Большое обновление: голосовой чат, новая графика и FPS-управление.**

## 🎙️ Войс-чат — теперь это обязательное условие зала
- **WebRTC P2P голос между всеми участниками зала** (хост + друзья-присяжные) — как Discord, но встроен прямо в игру и без сторонних программ.
- Игра сама запрашивает микрофон при создании/входе в зал. В HUD есть кнопка 🎙️ и клавиша `M`.
- **Без микрофона тоже можно**: вы всех слышите и просто не говорите (listen-only). Идеально для «посмотреть и покидать комки».
- **Сертификат теперь HTTPS** (самоподписанный, генерируется при первом запуске) — иначе браузеры не дают доступ к микрофону за пределами localhost. При первом открытии жмите «Дополнительно → Перейти на сайт». Опытные пользователи: `GAS_HTTP=1` отключает HTTPS (голос заработает только на localhost).
- Сигналинг WebRTC идёт через тот же игровой сервер (`/ws`, сообщения `signal`), публичный STUN для пробивания NAT; голос идёт напрямую между участниками.

## 🖼️ Графика, свет и текстуры
- **Процедурные текстуры**: паркет (ёлочка с сучками), обои с «дамаском», деревянные панели-«дадо», мраморные колонны с прожилками, ковёр с весами правосудия и золотой каймой, кессонный потолок.
- **Свет**: мягкая театральная подсветка обвинения (синяя) и защиты (бирюзовая), лучи из окон (аддитивные конусы), лампочки и золотые канделябры люстры, неоновая табличка **⚖ JUSTICE**.
- **Атмосфера**: дрейфующие пылинки в воздухе (90 частиц со свечением), искры при попаданиях комками и возражениях, всплывающие цифры (`+10`, `+убедительность`) прямо в 3D, вязаная bump-текстура носков (ткани теперь «видит» свет).

## 🖱️ Управление
- **FPS-захват мыши**: клик по залу — курсор скрывается, обзор мышью; `Esc` — отпустить.
- **Качка камеры** при ходьбе (голова следует за ногами), **FOV 72→77** при беге, **звук шагов**.

## 🎮 Играть с друзьями — полностью рабочие инструкции
1. Хост: главное меню → **🌐 ИГРАТЬ С ДРУЗЬЯМИ → 🏛️ СОЗДАТЬ ЗАЛ** → разрешить микрофон → скопировать ссылку и код.
2. Друзья: открыть ссылку на том же Wi-Fi (или через [Tailscale](https://tailscale.com)), принять предупреждение сертификата, ввести код, разрешить микрофон → **ВОЙТИ И ГОВОРИТЬ**.
3. Всё. Голос, голоса (влияют на вердикт), бумажные комки и чат — в реальном времени. Игра работает через HTTPS, поэтому микрофон разрешится и на телефоне.

## Полнота игры
Все версии, все 7 ролей, 6 колод доказательств, 4 темы зала, best-of-5 матчи, дневное дело, стример-режим, редактор носка Pro, 8 достижений, сохранение прогресса.

## Установка (Windows)
1. Скачайте `GUILTY-AS-SOCK-Scripter-Edition-Windows-x64.zip` из этого релиза.
2. Распакуйте в любую папку.
3. Запустите **`GUILTY AS SOCK - Scripter Edition.exe`**.
4. При первом запуске разрешите сеть (частные сети) и, когда игра попросит, микрофон.

> ⚠️ Windows SmartScreen может ругаться на неизвестного издателя — «Подробнее → Выполнить в любом случае». Это ожидаемо для фанатской сборки без платной подписи.

Исходный код и инструкции: https://github.com/squezech-cmd/scripter
